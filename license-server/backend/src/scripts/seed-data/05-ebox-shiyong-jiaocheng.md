### eBox 是什么？

**eBox**（也有用户叫 **2box**）是一款轻量级 Windows 多实例运行工具。它能让同一款程序在一台电脑上**同时运行多个实例**，每个实例拥有**独立的环境**——配置、缓存、聊天记录、登录状态完全隔离。

以企业微信为例：一台电脑上可以同时登录多个企微账号，互不干扰。它不改程序文件、绿色单文件**免安装**，属于"隔离式多开"思路（区别于会改程序的"多开器"，见《多开器是什么？为什么容易封号？》）。

下面从零开始，讲清 eBox 怎么用。

### 第一步：下载与安装

1. 从「下载」页获取 **eBox** 压缩包，解压得到 `eBox.exe`（绿色软件，**无需安装**）。
2. 建议把它放到固定位置（如 `D:\eBox\`），**不要放在桌面或临时文件夹**，避免误删。
3. 首次双击运行，如系统弹出安全提示，选择"仍要运行"。

> ⚠ 软件运行后会生成**环境数据目录**（默认 `C:\eBoxData` 或空间最大的盘），存放各账号的登录状态与聊天数据。**请勿手动删除、移动该文件夹**，否则所有账号的登录状态和聊天记录会全部丢失。

### 第二步：启动与激活

双击 `eBox.exe` 后会弹出**激活窗口**：

- **已有激活码**：复制激活码 → 粘贴到输入框 → 点击【激活】，完成授权；
- **没有激活码**：点击【购买激活码】跳转购买页，购买后回到窗口输入即可。

eBox 的激活码有四种类型，按需选择：

| 类型 | 说明 |
|---|---|
| 时长码 | 激活后按天数使用（如 30 天），到期可续费 |
| 绑定码 | 首次激活自动绑定本机，可限制每月解绑次数 |
| 在线码 | 联网使用，服务端实时校验授权 |
| 离线码 | 本地激活，不联网也可用完完整授权期限 |

激活成功后窗口关闭，进入主界面。

### 第三步：新建环境并启动应用

eBox 的核心概念是**环境**——**一个环境 = 一个账号的独立空间**。

**方法一：点【启动】按钮**

1. 在左侧环境列表选择一个环境（或新建环境）；
2. 点击环境卡片上的【启动】，或右侧的【启动新进程】；
3. 在文件选择窗口中选择目标程序（如企业微信的 `WXWork.exe`）；
4. 程序会在该环境内启动，首次启动会显示"首次启动加载中，请稍候…"。

**方法二：直接拖拽**

把程序的 `.exe`（或快捷方式）**直接拖到 eBox 窗口**，软件会自动选择或新建一个合适的环境运行。

> 提示：`.exe` 会自动选没有重名进程的环境；`.lnk`/`.url` 等只选空环境或新建环境。

### 第四步：多开多个账号

在**不同环境**里各启动一个应用，即可同时登录多个账号——每个账号配置、缓存、聊天记录相互独立。

建议启动后立刻**给环境改名**（如"销售一号""客服小张"）：

1. 点击环境卡片上的【改名】；
2. 输入新名称，确定即可。

这样卡片一眼可辨，管理多个账号时不会混乱。想快速找到某个账号，从它的卡片点【启动】，就能把对应窗口调到最前；隐藏到托盘的账号也能这样唤醒。

### 环境管理：改名 / 清理 / 结束 / 删除

| 操作 | 入口 | 说明 |
|---|---|---|
| 改名 | 卡片【改名】 | 自定义环境名称，便于区分账号 |
| 清理 | 卡片【清理】 | 可选"仅缓存 / 仅聊天记录 / 都清理"；仅清理会**不影响登录状态**，聊天记录清理后**不可恢复** |
| 结束进程 | 卡片上**右键** → 结束进程 | 关闭该环境内所有进程 |
| 删除环境 | 卡片上**右键** → 删除环境 | 删除环境及全部数据，**不可恢复**；有程序运行时需先结束进程 |

> 小贴士：磁盘快满或客户端卡顿时，先执行"仅缓存"清理；需要一次性大清理，可用顶部看板的**全盘垃圾清理**（磁盘卡片右下角垃圾桶图标）。

### 续费 / 解绑换机 / 更新

- **续费**：点击右上角【授权】→【重新激活/续期】→ 输入新码，续期后授权自动延长，**无需重装**；
- **解绑换机**：右上角【授权】→ 在"解绑次数"行点【解绑本机】→ 确认后**生成新换机码并自动复制到剪贴板**，到新电脑激活即可（注意每月解绑次数上限，且解绑后本机将无法继续使用）；
- **更新**：软件每 6 小时自动检查更新，标题栏出现红点时点击按提示更新即可，**不影响已激活授权和已有环境数据**。

### 常见问题（FAQ）

**Q1：同时最多能开几个？**
取决于电脑内存与磁盘空间，每个环境独立运行、互不干扰；可看顶部看板的内存占用，及时清理缓存。

**Q2：某个环境启动后没反应？**
多为首次加载较慢，稍等；若日志出现"失败/错误"，展开该环境复制日志发给客服。

**Q3：清理聊天记录会影响登录状态吗？**
不会，登录状态保留；但聊天记录本身会**永久删除**，请谨慎操作。

**Q4：授权到期了还能打开软件吗？**
可以打开查看界面，但无法再启动或新增环境，需续期。

**Q5：断网了还能用吗？**
在线码在离线宽限期内可正常使用；激活后即使暂时离线，也能用完完整授权期限。

**Q6：全盘垃圾清理会删聊天记录吗？会影响登录状态吗？**
会清理聊天图片/视频/文件（默认选中），但各环境的**登录状态、注册表、设备指纹受白名单保护，绝不删除**。

### 使用提醒

> eBox 为多实例环境隔离工具，**不提供**批量群发、定时发消息、自动回复、数据抓取、批量拉群、批量加好友等外挂功能，也**不收集、不上传**任何账号或聊天数据。依据微信/企业微信官方《用户外挂自查指南》，多开账号属于违规行为，**使用第三方工具存在账号受限或封禁风险**，请遵守平台条款与法律法规、合规使用、风险自担。

### 小结

- eBox = 免安装的隔离式多开工具，"一个环境 = 一个账号的独立空间"；
- 四步上手：下载解压 → 激活 → 新建环境启动应用 → 不同环境开不同账号；
- 记得及时改名、按需清理、妥善管理激活与解绑。
