# eBox 使用手册（企业微信多开版）

> eBox 是一款轻量级 Windows 多实例运行工具。以企业微信为例：一台电脑上可以同时登录多个企业微信账号，每个账号拥有**独立的环境**，互不干扰——配置、缓存、聊天记录完全隔离。

## 一、下载与安装

1. 从企业微信 / 邮件 / 网盘中下载 **eBox** 压缩包，解压得到 `eBox.exe`（绿色软件，**无需安装**）。
2. 建议把 `eBox.exe` 放到固定位置（如 `D:\eBox\`），不要放在桌面或临时文件夹，避免误删。
3. 首次双击运行 `eBox.exe`，如有系统安全提示，选择"仍要运行"。

> 软件运行后会生成环境数据目录（默认 `C:\eBoxData` 或空间最大的盘），里面存放各企业微信账号的登录状态与聊天数据。**请勿手动删除、移动该文件夹**，否则所有账号的登录状态和聊天记录会全部丢失。

## 二、启动与激活

### 2.1 首次运行激活

双击 `eBox.exe` 后，会弹出**激活窗口**：

- **已购买激活码**：复制激活码 → 粘贴到输入框 → 点击【激活】，即完成授权。
- **没有激活码**：点击【购买激活码】按钮，会跳转到购买页面（或联系客服购买），购买后回到激活窗口输入激活码即可。

### 2.2 激活码说明

| 类型 | 说明 |
|---|---|
| 时长码 | 激活后按天数计费使用（如 30 天），到期前可续费 |
| 绑定码 | 首次激活自动绑定本机，可限制每月解绑次数（如每月 1 次） |
| 在线码 | 激活后联网使用，服务端实时校验授权状态 |
| 离线码 | 本地激活，不联网也可使用完整授权期限 |

激活成功后窗口关闭，进入主界面。

## 三、查看授权信息

在主界面**右上角**点击【授权】按钮（或系统托盘图标 → "授权信息"），弹出**授权信息**窗口：

| 字段 | 说明 |
|---|---|
| 激活状态 | 已激活 / 未激活 / 已过期 / 已作废 |
| 在线状态 | 在线授权（已连接授权平台）／离线宽限（暂未连上，期间正常使用） |
| 到期时间 | 当前激活码的到期日期 |
| 当前版本 | 软件当前版本号（如 v2.9.2） |
| 本机指纹 | 本机唯一标识（绑定码激活后固定），用于换机/售后 |
| 解绑次数 | 本月已解绑次数／上限 |

窗口内还有【复制激活码】【重新激活/续期】【购买激活码】【联系客服】按钮，以及【解绑本机】入口（见第十、十一节）。

## 四、界面总览

主界面分为几个区域：

- **顶部看板**：CPU 使用率、内存使用、GPU 使用率、显存使用、磁盘使用 的实时曲线卡片（磁盘卡片右下角垃圾桶图标为**全盘垃圾清理**入口，见[第六章](#六全盘垃圾清理)）。
- **提示横幅**：启用进程后建议改环境名称；下次如需再次启动对应进程，无需重新新建，直接启动该环境即可。
- **左侧环境列表**：显示所有环境，支持【卡片视图 / 列表视图】切换；顶部有环境统计（环境 N 个，在线 N 个）。
- **环境卡片**：每个账号对应一张卡片，含【启动】【改名】【清理】【关闭】按钮，显示在线状态、进程数量、已运行时间。
- **空态页面**：未创建环境时显示"用户须知"与"使用事项"。

## 五、查看系统配置信息

### 5.1 顶部实时看板

主界面顶部的曲线卡片实时展示本机系统资源占用：

- **CPU 使用率**（%）
- **内存使用**（已用 / 总量）
- **GPU 使用率**（%）
- **显存使用**（已用 / 总量）
- **磁盘使用**（各盘使用率，**点击卡片标题可切换盘符**，点击**右下角垃圾桶图标**可进入"全盘垃圾清理"，见[第六章](#六全盘垃圾清理)）

### 5.2 环境信息面板

在环境卡片中点击查看（展开）环境详情，可看到该账号环境的完整配置信息：

| 字段 | 说明 |
|---|---|
| 环境名称 | 环境自定义名称 |
| 环境索引 | 环境编号 |
| 应用路径 | 该环境绑定的程序路径（未绑定显示"未绑定，启动后自动绑定"） |
| 环境目录 | 数据存放路径 |
| 进程内存占用 | 该环境所有进程当前内存占用 |
| 环境数据总大小 / 缓存大小 / 聊天记录大小 | 各类型数据占用 |
| 设备码 machine_id | 企业微信设备标识（启动后自动生成） |
| 注册表 hive | 环境专属注册表文件与加载状态 |
| 腾讯 qimei | 设备特征标识（如显示"企微不生成"表示不影响登录） |

面板提供【复制】（一键复制全部信息，方便发客服排查）和【清理】按钮。

## 六、全盘垃圾清理

磁盘空间不足或系统变慢时，可使用 eBox 的**全盘垃圾清理**功能：一键扫描所有磁盘，按分类清理系统垃圾、应用缓存、聊天软件缓存与聊天文件，以及各 eBox 多开环境内的缓存与聊天记录。

### 6.1 入口

主界面顶部看板最右侧为**磁盘使用卡片**：

- **点击卡片标题**（如"磁盘 C"）可**切换盘符**，逐个查看各磁盘的使用率。
- **点击卡片右下角的垃圾桶图标**（鼠标悬停显示"全盘垃圾清理"提示），弹出清理确认框。

### 6.2 清理范围

点击垃圾桶后先弹出确认框，明确列出本次将执行的操作：

| 类别 | 清理内容 |
|---|---|
| 系统垃圾 | 系统临时文件、Windows 更新缓存、预读取缓存、错误报告、崩溃转储、旧系统/升级残留、回收站（彻底清空） |
| 应用缓存 | 浏览器缓存（Chrome/Edge 等）、缩略图/图标缓存、开发工具缓存（pip/npm/Gradle 等）、其他应用缓存与日志 |
| 聊天软件 | 微信/企业微信/QQ/TIM/钉钉 的缓存、聊天图片、聊天视频、聊天文件、日志 |
| eBox 环境 | 各多开环境内的缓存与聊天记录（按环境分组，**不影响登录状态**） |
| 散落垃圾 | 全盘 `*.tmp` / `*.dmp` / Thumbs.db / 未完成下载 等散落垃圾文件；虚拟机（VMware/VBox）日志与转储 |

默认**不清理**：IIS 服务器日志、QQ/TIM 接收保存的文件（如需要可另行处理）。

### 6.3 清理流程

1. 点击垃圾桶图标 → 阅读确认框 → 点【是】。
2. 弹出 **UAC 管理员授权窗口** → 点【是】。
3. 工具并行扫描所有磁盘（实时进度条）：① 扫描垃圾目录/文件清单 → ② 统计各项目大小 → ③ 展示扫描结果表（编号 / 分类 / 项目 / 大小 / 说明），并显示"将清理 X / 可清理总计 Y"。
4. 若检测到浏览器、微信、企业微信、QQ/TIM、钉钉正在运行，工具会**自动关闭**它们（含 eBox 多开中的对应进程），以释放被占用的缓存文件。
5. 随后自动开始清理（默认按安全配置全选），每个项目清理完成即显示释放的空间。
6. 清理完成后，如提示可重启电脑，重启可释放更多被系统占用的空间。

> 清理过程需要几分钟（内容多时更久），请耐心等待，勿中途关闭窗口。

### 6.4 重要说明与警告

⚠ 清理前请务必阅读：

- **永久删除，不可恢复**。聊天图片/视频/文件、回收站内容一旦清理无法找回，请先确认无需保留（并保存正在编辑的文档）。
- 清理会**自动关闭正在运行的聊天软件与浏览器**，请提前保存工作内容。
- 需要**管理员权限**（弹出 UAC 授权窗口）。
- eBox **环境关键文件绝不删除**：各环境的登录状态、注册表 hive、企业配置、设备指纹（machine_id / qimei）均受保护；清理范围与"环境卡片 → 清理"按钮的**白名单完全一致**，只清理缓存目录与聊天消息库。

### 6.5 与"环境清理"按钮的区别

| 方式 | 入口 | 范围 | 影响 |
|---|---|---|---|
| 环境卡片【清理】 | 环境卡片 → 清理 | 仅该环境 | 可选"仅缓存 / 仅聊天记录 / 都清理" |
| 全盘垃圾清理 | 磁盘卡片 → 垃圾桶 | 所有磁盘 + 所有环境 | 系统/应用/聊天软件/环境 一次性全量清理 |

> 建议：日常小清理用"环境卡片 → 仅缓存"；磁盘快满或系统明显变慢时，用全盘垃圾清理一次性解决。

## 七、启动企业微信（启动进程）

### 方法一：点击【启动进程】

1. 在左侧环境列表选择一个环境（或新建环境）。
2. 点击环境卡片上的【启动】按钮，或右侧的【启动新进程】。
3. 在弹出的文件选择窗口中选择**企业微信的可执行文件**（如 `WXWork.exe`）。
4. 程序会自动在该环境内启动企业微信，首次启动会显示"首次启动加载中，请稍候…"。

### 方法二：直接拖拽

把企业微信的 `WXWork.exe`（或快捷方式）**直接拖到 eBox 窗口**中，软件会自动选择或新建一个合适的环境运行。

> - `.exe` 文件会自动选择没有重名进程的环境运行；
> - `.lnk` 快捷方式或 `.url` 等其他类型只会选择空环境或新建环境运行（也可自行指定环境）。

### 多开多个账号

按上述方法重复操作，在**不同环境**中各启动一个企业微信，即可同时登录多个账号——每个账号的配置、缓存、聊天记录相互独立，互不干扰。

## 八、环境管理

### 8.1 改名称

1. 点击环境卡片上的【改名】按钮。
2. 输入新名称（如"销售一号""客服小张"），点击确定。
3. 建议启动进程后立即改名，方便区分多个账号。

### 8.2 清理内容

点击环境卡片上的【清理】按钮，弹出清理对话框，可选：

| 选项 | 作用 | 影响 |
|---|---|---|
| **仅缓存** | 清理该环境企业微信的 CEF 渲染缓存（qtCef、WXWorkCefCache、GPU 着色器等），下次启动自动重建 | 不影响聊天记录、登录状态、企业配置、会话数据 |
| **仅聊天记录** | 清理该环境企业微信的聊天记录（Profiles/Data 消息库、搜索索引 Index 等） | ⚠ 聊天记录**永久删除无法恢复**，登录状态保留 |
| **缓存与聊天记录** | 同时清理以上两者 | ⚠ 聊天记录永久删除无法恢复 |

> 清理后环境仍可正常使用；当磁盘空间不足或客户端卡顿时，建议先执行"仅缓存"清理。

### 8.3 结束进程

在环境卡片上**点击右键** → 选择【结束进程】，即可结束该环境内正在运行的所有进程（企业微信窗口随之关闭）。

### 8.4 删除环境

1. 在环境卡片上**点击右键** → 选择【删除环境】。
2. 若环境中仍有程序在运行，会提示"环境中仍有正在运行的程序时无法删除"，请先结束进程。
3. 确认后删除该环境及其全部数据（登录状态、聊天记录一并删除）。

> ⚠ 删除环境不可恢复，请先确认该账号的数据无需保留。

## 九、查看进程与日志

### 9.1 进程记录

展开环境详情可查看**进程记录**：该环境内所有正在运行的进程（显示 PID 与进程路径），支持【添加进程】继续添加、右上角【折叠/展开】。

### 9.2 环境日志

每个环境都有独立的**日志面板**，记录环境运行全过程：

- 日志类型：信息 / 环境 / 进程 / 登录 / 提示 / 错误
- 日志状态：成功 / 失败 / 信息
- 支持【查看 / 收起】面板、【清理】清空当前缓存日志
- 右键日志面板可【复制最近 10 条】、【复制最近 50 条】、【复制全部（当前缓存）】，方便发送给客服排查问题

> 日志只保存在本机，用于排查环境异常；若企业微信登录异常，把复制出来的日志发给客服即可快速定位。

## 十、续费 / 重新激活

激活码到期前，主界面标题栏会显示到期时间（如"到期：2026-09-07"），到期后无法再启动环境和新增环境，但可以正常查看界面。

**续费步骤**：

1. 点击右上角【授权】→ 打开授权信息窗口。
2. 点击【重新激活/续期】。
3. 输入新的激活码（购买的新码），点击确定。
4. 提示"续期成功，感谢支持！"即完成。

> 续期后授权时间自动延长，无需重装软件。

## 十一、解绑换机

当需要把当前激活码**转移到另一台电脑**使用时：

1. 点击右上角【授权】→ 打开授权信息窗口。
2. 在"解绑次数"一行点击【解绑本机】。
3. 确认弹窗（会提示本月剩余解绑次数），点击"是"。
4. 解绑成功后会**生成新的换机激活码并自动复制到剪贴板**，请保存好该新码，到新电脑上激活即可。

注意事项：

- **绑定码**才可解绑；非绑定码显示"无需解绑"。
- 解绑次数有上限（如每月 1 次），用尽后需下月再试或联系客服。
- 解绑后本机将无法继续使用，应用会自动关闭。
- 解绑时若有其他 eBox 进程在运行，请先全部关闭后再操作。

## 十二、更新升级

1. 软件启动时自动检查更新（每 6 小时一次），发现新版本时**标题栏出现红点**。
2. 点击红点（或托盘菜单"检查更新"），弹出更新窗口，显示新版本号、发布日期、包大小、更新内容。
3. 点击【立即更新】→ 显示下载进度（已下载 x.x / x.x MB，xx%）。
4. 下载完成后确认安装，程序自动退出并重启为新版本（自动完成，无需手动操作）。
5. 点击【以后再说】则本次跳过，有新版本时再次提示；若提示"已忽略此版本"，有新版本时会再提醒。

> 更新不会影响已激活的授权和已有环境数据；如果更新失败会自动恢复原版本，重试即可。

## 十三、关闭应用与托盘

点击主界面右上角关闭按钮（×）时，会弹出选择：

- **缩小到托盘**：eBox 继续在后台运行，环境中的进程不受影响（托盘图标仍在）。
- **退出应用**：**先强制结束所有环境中的进程**，再退出 eBox（企业微信全部关闭）。
- **取消**：什么都不做，回到主界面。

> **重要**：选择"退出应用"会关闭所有环境中的企业微信进程，请先保存正在处理的工作。

托盘图标（右下角小图标）右键菜单：

| 菜单 | 作用 |
|---|---|
| 退出(X) | 结束所有环境进程并退出 eBox |
| 启动新进程(N) | 直接选择程序启动新进程 |
| 显示主界面(S) | 重新打开主窗口 |

## 十四、常见问题与注意事项

**Q1：同时最多能开几个企业微信？**
数量取决于电脑内存与磁盘空间，每个环境独立运行互不干扰；建议内存占用较高时用顶部看板观察，及时清理缓存。

**Q2：为什么某个环境启动后没反应？**
展开该环境查看日志与进程记录，通常为首启加载较慢，稍等片刻；若日志出现"失败/错误"，复制日志发给客服。

**Q3：换电脑后怎么继续用？**
先在旧电脑上【解绑本机】获取换机码 → 在新电脑安装 eBox → 用换机码激活即可（注意每月解绑次数限制）。

**Q4：清理聊天记录会影响登录状态吗？**
不会，登录状态保留；但聊天记录本身会永久删除，请谨慎操作。

**Q5：授权到期了还能打开软件吗？**
可以打开查看界面，但无法再启动环境、新增环境；需购买新码并在【授权】中续期。

**Q6：断网了还能用吗？**
在线激活码在离线宽限期内可正常使用；激活后即使暂时离线，也能用完完整的授权期限。

**Q7：全盘垃圾清理会删掉我的聊天记录吗？**
会。微信/企业微信/QQ/钉钉 的聊天图片、视频、文件在清理范围内（默认选中）。如不想删除，请在清理前手动备份，或仅使用"环境卡片 → 仅缓存"。

**Q8：全盘清理会影响 eBox 环境的登录状态吗？**
不会。各环境的登录状态、注册表 hive、企业配置、设备指纹（machine_id / qimei）被白名单保护，绝不删除；只清理缓存目录与聊天消息库。清理后环境内重新启动企业微信即可正常使用。

**Q9：清理时为什么要求关闭程序并需要管理员权限？**
关闭浏览器/聊天软件是为了释放正在被占用的缓存文件（否则删不掉）；管理员权限用于清理系统目录（Windows 更新缓存、错误报告、回收站等），清理过程会弹出 UAC 授权窗口，属正常现象。

**Q10：易歪歪发送含图片的话术，图片发不出去（只有文字）？**
如果易歪歪安装在 C 盘（尤其是"文档"等系统用户目录下），会被 eBox 的环境隔离重定向，多开的企业微信读取不到图片文件，所以只发出文字。
解决办法：**把易歪歪卸载后安装到 D 盘（或其他非 C 盘）**，重新打开即可正常发送图片。

## 妙用小技巧

- **快速定位账号**：当企业微信多个账号，想快速找到这个号时，从应用的卡片对应微信点【启动】，可快速弹出对应微信到前置窗口。
- **自动登录免扫码**：登录企业微信后，勾选自动登录，下次电脑重启或者退出登录等，只需点卡片的【启动】按钮，可快速启动并自动登录企业微信，无需扫码和验证码。
- **磁盘清理建议**：硬盘卡片饼状图如果超过 85% 以上建议清理，全盘清理或者单独个号清理，释放缓存空间，更流畅。
- **关闭指定企业微信**：想关闭指定企业微信，点【关闭】的结束进程即可。
- **卡片排序**：左侧微信号卡片支持点击长按鼠标左键，上下移动卡片排序。
- **列表视图**：微信号过多，可以在左侧切换列表视图，看起来更紧凑，看到更多环境。
- **及时更新**：有新版本，建议更新，以获得更好的使用体验，数据不会丢失，登录持久有效，放心更新。
