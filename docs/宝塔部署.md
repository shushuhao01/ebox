# eBox 授权服务平台 · 宝塔部署文档

> 部署域名：**abc222.cn**
> 适用：宝塔面板（Nginx + MySQL 8 + Node.js 22）+ 一台云服务器（推荐 2C4G 起）
> 配套脚本：`license-server/deploy/`（deploy.sh 首次部署 / update.sh 更新 / backup.sh 备份）

## 1. 部署拓扑

```
eBox 客户端 (WinHTTP) ──https──► abc222.cn:443 (Nginx)
管理面板 (浏览器)      ──https──► abc222.cn:443 (Nginx 静态 + /api 反代)
                                      │
                                      ▼
                             127.0.0.1:3008 (Node/Express/PM2)
                                      │
                                      ▼
                               MySQL 8 (license_server)
```

- 客户端接口：`POST /api/v1/activate|heartbeat|unbind`
- 管理接口：`/api/admin/*`（JWT）
- 管理面板前端：`admin/dist` 静态文件，与 API 同源，无需 CORS

## 2. 前置准备（宝塔面板操作）

1. **域名解析**：在域名服务商把 `abc222.cn` 与 `www.abc222.cn` 的 A 记录指向服务器公网 IP。
2. **建站**：宝塔「网站 → 添加站点」→ 域名 `abc222.cn`、根目录 `/www/wwwroot/license-server`（PHP 纯静态即可）。
3. **Node.js**：宝塔软件商店安装「Node.js 版本管理器」，启用版本 **>= 22**；终端执行 `node -v` 确认。
4. **PM2**：终端执行 `npm install -g pm2`。
5. **MySQL**：软件商店安装 MySQL 8 并启动。数据库账号建议面板创建：库名 `license_server`、账号 `license`（仅授权该库即可）。

## 3. 上传代码

在本机（Windows）把 `license-server` 整包传到服务器 `/www/wwwroot/license-server`：

```powershell
# 本机 PowerShell 示例（需先装 rsync，或直接用宝塔文件管理器上传 zip 解压）
rsync -av --exclude node_modules --exclude dist ./license-server/ root@服务器IP:/www/wwwroot/license-server/
```

**必须保留**：`backend/package-lock.json`、`admin/package-lock.json`、`database/schema.sql`、`backend/.env.example`、`deploy/`。

## 4. 首次部署

```bash
cd /www/wwwroot/license-server
chmod +x deploy/*.sh
bash deploy/deploy.sh
```

脚本会自动完成：后端依赖安装与构建 → 前端构建 → 生成 `.env` → 初始化数据库 → 创建管理员 → PM2 启动。

执行后**立即编辑** `/www/wwwroot/license-server/backend/.env`：

| 变量 | 说明 |
|---|---|
| `DB_PASSWORD` | 改成真实 MySQL 密码 |
| `JWT_SECRET` | 改成随机长字符串 |
| `LICENSE_PRIVATE_KEY_D` | **保留默认出厂密钥**（与 eBox 客户端内置公钥配对）；如已用 KeyGen 换过密钥，则改成对应私钥 d 标量 |

> 密钥核对：在 `backend` 目录执行 `npm run gen:key`，对比输出的公钥是否与客户端内置公钥一致（`d:\Projects\2Box-master\eBox\biz\license\License.cpp` 中 `kPublicKeyBlob`）。

若 deploy.sh 因 DB 密码未填而跳过导表，手动导入一次即可（宝塔「数据库 → 导入」选 `license-server/database/schema.sql`），再执行 `npm run init:db && npm run init:admin`。

## 5. 配置 Nginx 与 SSL

1. 打开宝塔「网站 → abc222.cn → 配置文件」，替换为 `license-server/deploy/nginx/abc222.cn.conf` 的内容（路径按注释核对）。
2. 宝塔「网站 → abc222.cn → SSL」→ 申请 Let's Encrypt 证书（自动续签），保存后自动写入 `abc222.cn.conf` 中引用的证书路径。
3. 保存配置 → 重载 Nginx。

验证：

```bash
curl -k https://abc222.cn/health
# {"success":true,"message":"eBox License Server OK",...}
```

浏览器打开 `https://abc222.cn` → 管理员登录页（账号为 deploy.sh 设置的 `ADMIN_USERNAME/ADMIN_PASSWORD`，默认 `admin/admin123`，登录后请修改）。

## 6. 客户端对接

- eBox 客户端默认连接 **`https://abc222.cn`**（编译期内置），无需配置。
- **换域名 / 本地联调**：写注册表覆盖，免重新编译：

```powershell
reg add "HKCU\Software\2Box" /v ServerUrl /t REG_SZ /d "https://新域名" /f
reg add "HKCU\Software\2Box" /v ServerUrl /t REG_SZ /d "http://127.0.0.1:3008" /f   # 本地联调
```

- 本地联调时先在 `license-server/backend` 跑 `npm run dev:local`，再用 KeyGen 生成码在客户端实测「激活 → 面板显示首次激活 → 换机 → 作废 → 心跳下线」完整闭环。

## 7. 双轨互不干扰说明（重要）

| 场景 | 行为 |
|---|---|
| 离线 KeyGen 生成的码（服务器未登记） | 客户端激活/使用完全正常，心跳自动停止，服务端宽容放行，**不受作废/换机管控** |
| 服务器不可达（断网/未部署） | 非强制在线模式下按离线放行，照常使用 |
| 面板在线生成的码（已登记） | 受完整管控：在线激活校验、心跳作废/强制下线、服务端换机、离线宽限（默认 7 天） |

即：本机开发机的离线码与在线版本互不干扰，均可正常使用。

## 8. 日常运维

| 操作 | 命令 |
|---|---|
| 查看运行状态 | `pm2 status` / `pm2 logs license-server` |
| 更新版本 | 重新上传代码后 `bash deploy/update.sh` |
| 手动备份 | `bash deploy/backup.sh`（默认保留最近 30 份到 `backups/`） |
| 定时备份 | crontab 添加：`0 3 * * * bash /www/wwwroot/license-server/deploy/backup.sh >> /www/wwwroot/license-server/deploy/backup.log 2>&1` |
| 恢复备份 | `gunzip -c backups/license_server_时间戳.sql.gz \| mysql -ulicense -p你的密码 license_server` |
| 查看日志 | `tail -f backend/logs/pm2-out.log` |

## 9. 常见问题

- **`/health` 404 / 502**：确认 PM2 已启动（`pm2 status`），且 Nginx 已反代。
- **前端白屏**：确认 Nginx `root` 指向 `/www/wwwroot/license-server/admin/dist`，且 `try_files` 已配。
- **客户端激活提示「无法连接授权服务器」且是强制在线模式**：检查 `ServerUrl` 注册表是否残留指向本地；删除该注册表项即回默认 `https://abc222.cn`。
- **面板显示"首次激活"为空**：只有时长制（verMinor==8）码在线激活后才登记 `used_at`，离线码不登记属正常。
- **换机码生成失败**：检查 `.env` 的 `LICENSE_PRIVATE_KEY_D` 与客户端公钥是否配对（`npm run gen:key` 核对）。
