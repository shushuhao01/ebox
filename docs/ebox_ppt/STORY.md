# STORY.md — eBox 沙箱多开工具使用指南

## ① 用户意图对齐

- **目标受众**：eBox 终端用户（需要在一台电脑上多开企业微信账号的运营/销售人员），场合为产品使用培训 / 新手入门教程。
- **核心目标**：看完后用户能独立完成「下载 → 激活 → 启动多开 → 管理环境 → 续费/换机/更新」全流程，并知道遇到问题如何自查（看日志、找客服）。
- **PPT 长度**：19 页（Hero 配额 4 页：封面、界面总览、多开原理、结束页）。
- **视觉调性**：科技清爽 / 蓝白商务 / 截图实证 / 大气简洁。
- **内容边界**：必讲——下载、运行、激活、启动新进程、改名、环境信息、清理缓存/聊天记录、环境卡片再次启动、结束进程 vs 删除环境、续费、解绑、更新、FAQ；不讲——内部技术实现、授权服务端细节；禁碰——任何与官方手册不一致的操作描述。

## ② 页面布局骨架

- **总页数 19**，不分章节页（教程型连贯叙事，用流程总览页代替分章）。
- **Hero 页**：P1 封面、P4 界面总览（截图标注高潮）、P9 多开隔离原理、P19 结束页。占比 4/19 ≈ 21%，两两间隔 ≥ 2 页。
- **rhythm 曲线**：P1 peak → P2 valley → P3 transition（流程） → P4 peak → P5-P8 valley → P9 peak → P10-P13 valley → P14 transition（对比转折） → P15-P18 valley → P19 peak。
- **非对称版式预算**：P2 非对称双栏、P4 左大图+右侧文字、P5 非对称双栏、P7 左大图+右侧文字、P9 巨型数字+洞察、P10 非对称双栏、P14 非对称双栏、P17 非对称双栏 → 8/19 ≈ 42%（≥40% ✓）。其中「左大图+右侧文字」与「非对称双栏」合计 7/19 ≈ 37%（≤40% ✓）。
- **对称版式预算**：仅 P12（3 卡片横排-清理选项）1 页使用 N卡片横排（≤2 ✓）。
