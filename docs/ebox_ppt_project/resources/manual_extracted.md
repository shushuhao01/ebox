eBox 使用手册（QYWX多开版）
eBox 是一款轻量级 Windows 多实例运行工具。以qw为例：一台电脑上可以同时登录多个账号，每个账号拥有独立的环境，互不干扰——配置、缓存、聊天记录完全隔离。

三、查看授权信息
在主界面右上角点击【授权】按钮（或系统托盘图标 → &quot;授权信息&quot;），弹出授权信息窗口：
窗口内还有【复制激活码】【重新激活/续期】【购买激活码】【联系客服】按钮，以及【解绑本机】入口（见第九、十节）。
四、界面总览
主界面分为几个区域：
顶部看板：CPU 使用率、内存使用、GPU 使用率、显存使用、磁盘使用 的实时曲线卡片。
提示横幅：启用进程后建议改环境名称；下次如需再次启动对应进程，无需重新新建，直接启动该环境即可。
左侧环境列表：显示所有环境，支持【卡片视图 / 列表视图】切换；顶部有环境统计（环境 N 个，在线 N 个）。
环境卡片：每个账号对应一张卡片，含【启动】【改名】【清理】【关闭】按钮，显示在线状态、进程数量、已运行时间。
空态页面：未创建环境时显示&quot;用户须知&quot;与&quot;使用事项&quot;。

CPU 使用率（%）

显存使用（已用 / 总量）

在环境卡片中点击查看（展开）环境详情，可看到该账号环境的完整配置信息：
面板提供【复制】（一键复制全部信息，方便发客服排查）和【清理】按钮。

七、环境管理
7.1 改名称
点击环境卡片上的【改名】按钮。
输入新名称或wx号（如&quot;销售一号&quot;&quot;abc123&quot;），点击确定。
建议启动进程后立即改名，方便区分多个账号。
7.2 清理内容
点击环境卡片上的【清理】按钮，弹出清理对话框，可选：
清理后环境仍可正常使用；当磁盘空间不足或客户端卡顿时，建议先执行&quot;仅缓存&quot;清理。
7.3 结束进程
在环境卡片上点击右键 → 选择【结束进程】，即可结束该环境内正在运行的所有进程（企业微信窗口随之关闭）。
7.4 删除环境
在环境卡片上点击右键 → 选择【删除环境】。
若环境中仍有程序在运行，会提示&quot;环境中仍有正在运行的程序时无法删除&quot;，请先结束进程。
确认后删除该环境及其全部数据（登录状态、聊天记录一并删除）。
⚠ 删除环境不可恢复，请先确认该账号的数据无需保留。
八、查看进程与日志
8.1 进程记录
展开环境详情可查看进程记录：该环境内所有正在运行的进程（显示 PID 与进程路径），支持【添加进程】继续添加、右上角【折叠/展开】。
8.2 环境日志
每个环境都有独立的日志面板，记录环境运行全过程：
日志类型：信息 / 环境 / 进程 / 登录 / 提示 / 错误
日志状态：成功 / 失败 / 信息
支持【查看 / 收起】面板、【清理】清空当前缓存日志
右键日志面板可【复制最近 10 条】、【复制最近 50 条】、【复制全部（当前缓存）】，方便发送给客服排查问题
日志只保存在本机，用于排查环境异常；若企业微信登录异常，把复制出来的日志发给客服即可快速定位。
九、续费 / 重新激活
激活码到期前，主界面标题栏会显示到期时间（如&quot;到期：2026-09-07&quot;），到期后无法再启动环境和新增环境，但可以正常查看界面。
续费步骤：
点击右上角【授权】→ 打开授权信息窗口。
点击【重新激活/续期】。
输入新的激活码（购买的新码），点击确定。
提示&quot;续期成功，感谢支持！&quot;即完成。
续期后授权时间自动延长，无需重装软件。
十、解绑换机
当需要把当前激活码转移到另一台电脑使用时：
点击右上角【授权】→ 打开授权信息窗口。
在&quot;解绑次数&quot;一行点击【解绑本机】。
确认弹窗（会提示本月剩余解绑次数），点击&quot;是&quot;。
解绑成功后会生成新的换机激活码并自动复制到剪贴板，请保存好该新码，到新电脑上激活即可。
注意事项：
绑定码才可解绑；非绑定码显示&quot;无需解绑&quot;。
解绑次数有上限（如每月 1 次），用尽后需下月再试或联系客服。
解绑后本机将无法继续使用，应用会自动关闭。
解绑时若有其他 eBox 进程在运行，请先全部关闭后再操作。
十一、更新升级
软件启动时自动检查更新（每 6 小时一次），发现新版本时标题栏出现红点。
点击红点（或托盘菜单&quot;检查更新&quot;），弹出更新窗口，显示新版本号、发布日期、包大小、更新内容。
点击【立即更新】→ 显示下载进度（已下载 x.x / x.x MB，xx%）。
下载完成后确认安装，程序自动退出并重启为新版本（自动完成，无需手动操作）。
点击【以后再说】则本次跳过，有新版本时再次提示；若提示&quot;已忽略此版本&quot;，有新版本时会再提醒。
更新不会影响已激活的授权和已有环境数据；如果更新失败会自动恢复原版本，重试即可。
十二、关闭应用与托盘
点击主界面右上角关闭按钮（×）时，会弹出选择：
缩小到托盘：eBox 继续在后台运行，环境中的进程不受影响（托盘图标仍在）。
退出应用：先强制结束所有环境中的进程，再退出 eBox（企业微信全部关闭）。
取消：什么都不做，回到主界面。
重要：选择&quot;退出应用&quot;会关闭所有环境中的企业微信进程，请先保存正在处理的工作。

十三、常见问题与注意事项
Q1：同时最多能开几个？ 数量取决于电脑内存与磁盘空间，每个环境独立运行互不干扰；建议内存占用较高时用顶部看板观察，及时清理缓存。
Q2：为什么某个环境启动后没反应？ 展开该环境查看日志与进程记录，通常为首启加载较慢，稍等片刻；若日志出现&quot;失败/错误&quot;，复制日志发给客服。
Q3：换电脑后怎么继续用？ 先在旧电脑上【解绑本机】获取换机码 → 在新电脑安装 eBox → 用换机码激活即可（注意每月解绑次数限制）。
Q4：清理聊天记录会影响登录状态吗？ 不会，登录状态保留；但聊天记录本身会永久删除，请谨慎操作。
Q5：授权到期了还能打开软件吗？ 可以打开查看界面，但无法再启动环境、新增环境；需购买新码并在【授权】中续期。
Q6：断网了还能用吗？ 在线激活码在离线宽限期内可正常使用；激活后即使暂时离线，也能用完完整的授权期限。
