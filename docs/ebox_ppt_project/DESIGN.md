# DESIGN.md — eBox 使用指南 设计稿

> 场景判定：软件使用教学 / 产品介绍 → 不命中学术/咨询/红金三预设，走通用设计原则原创设计。

## 1. 画布与母版（A/B/C 三区）

- 画布：1280×720；页面 padding：上下 20px、左右 64px。
- **A · 标题块**：0–120px。左侧 8px 主色竖条 + 主标题 34px bold + 副标题 15px 灰字。全篇位置固定。
- **B · 内容区**：120–660px（可用 540px）。
- **C · 页脚条**：660–720px。左侧 icon_256.png 20px + 「eBox 使用指南」14px 灰字；右侧页码 `NN / 19` 14px 灰字。封面/章节页/结束页省略 C 区。
- L3 母版徽标：icon_256.png，固定页脚左侧，全篇一致。

## 2. 颜色系统（4 hex + 中性色）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主色 | `#2563EB` | 标题竖条、编号徽章、按钮色、章节大字、步骤编号 |
| 辅色 | `#06B6D4` | 渐变终点、次强调、图标辅助 |
| 强调色 | `#F59E0B` | 警示条、关键提醒（到期/不可恢复） |
| 文本主色 | `#0F172A` | 标题、正文 |
| 中性色 | `#64748B` 灰文 / `#FFFFFF` 背景 / `#EFF6FF` 浅蓝面板 / `#F1F5F9` 浅灰面板 / `#E2E8F0` 边框 | 辅助文本、卡片底、分隔 |
| 警示红 | `#DC2626`（仅 P15 删除环境侧 + 清理警示，面积 ≤8%） | 不可逆操作警示 |

- **渐变方案**：`linear-gradient(135deg, #2563EB 0%, #06B6D4 100%)`——封面/章节页/结束页背景（加深蒙版 `linear-gradient(135deg,#1E3A8A,#0E7490)`）、步骤编号圆、大数字。
- **半透明**：浅色面板 `rgba(37,99,235,0.06)`；截图卡片阴影 `0 8px 24px rgba(15,23,42,0.10)`。
- **面积分配**：常规页 主色≤15%（点缀）、辅色≤20%、强调≤5%、白底为主；Hero/封面页 主色+辅色渐变面积可达 70%，强调色 10-15%。

## 3. 字体系统

| 层级 | 字号 | 字重 | 说明 |
| :--- | :--- | :--- | :--- |
| 封面主标题 | 64px | bold | 仅封面，思源黑体 |
| 章节大字 | 60px | bold | 章节页 |
| 巨型数字/锚点 | 56–96px | bold | 章节号、对比页大字 |
| 页面主标题 | 34px | bold | A 区固定 |
| 副标题/卡片标题 | 20–24px | 600 | 卡片头 |
| 正文 | 16–18px | normal | lineHeight 1.55 |
| 辅助/脚注/页码 | 13–14px | normal | #64748B |

- 字体家族：**思源黑体（Source Han Sans SC）** 全篇统一；西文/数字同族。锚点数字用 bold + 主色渐变字。

## 4. 截图标注规范（本项目特色）

- 截图置于 `position: relative` 容器内，容器尺寸 = 图片等比缩放（原图 1024×768，4:3）。
- 编号徽章：28×28 圆形、主色底白字 15px bold、`position: absolute`，坐标按缩放比从原图坐标换算。
- 图例：截图旁/下方配编号对应的说明卡（编号徽章同款样式，保持视觉联动）。
- 截图加 1px `#E2E8F0` 边框 + 12px 圆角 + 阴影，模拟软件窗口质感。

## 5. 信息密度门禁

- 常规内容页正文 ≥ 180 字，留白 ≤ 35%；主视觉占 B 区 ≥ 30%（截图页 ≥ 50%）。
- 卡片填充率 ≥ 85%，尾部元素（标签/警示条）用 `marginTop: 'auto'` 锚底。
- 每个视觉锚点（大截图/大数字/大色块）周围留白 ≥ 40px。
