# STORY.md — eBox 使用指南 PPT 叙事逻辑

## ① 用户意图对齐

- **目标受众**：eBox 新用户 / 售后培训场景。用于向刚购买或准备使用 eBox（企业微信多开沙箱工具）的用户做使用教学，也可作为客服培训材料。
- **核心目标**：看完后用户能够独立完成「下载 → 激活 → 启动多开 → 日常维护 → 续费/换机」全流程；记住三条铁律：不要手动删环境数据目录、删除环境不可恢复、退出应用会关闭所有进程。
- **PPT 长度**：19 页（Hero 配额 4 页：封面、界面总览、结束进程 vs 删除环境、结束页）。
- **视觉调性**：科技清爽 / 软件教学 / 大气商务浅蓝。
- **内容边界**：必讲——下载渠道、激活、授权信息、界面总览、启动新进程（两种方法）、改名、再次启动、环境信息、进程与日志、清理缓存/聊天记录、结束进程与删除环境的区别、续费、解绑换机、更新升级、托盘与退出、常见问题。不讲——软件内部实现原理、开发架构。禁碰——任何绕过授权/破解的内容。

## ② 页面布局骨架（19 页 / 3 章）

- **开篇**：P1 封面(hero/peak) → P2 目录(supporting/valley)
- **第一章 快速上手**：P3 章节页(transition) → P4 下载与安装(valley) → P5 首次激活(valley) → P6 授权信息解读(peak，截图标注)
- **第二章 环境多开实战**：P7 章节页(transition) → P8 界面总览(hero/peak，全图标注) → P9 启动新进程(valley) → P10 改名与再次启动(valley) → P11 环境信息面板(valley) → P12 进程与日志(peak，双截图)
- **第三章 维护与售后**：P13 章节页(transition) → P14 清理缓存/聊天记录(valley) → P15 结束进程 vs 删除环境(hero/peak，警示对比) → P16 续费与解绑(valley) → P17 更新升级与托盘(peak，进度视觉) → P18 常见问题(valley) → P19 结束页(hero/peak)
- **节奏检查**：valley 最长连续段 = P9-P11（3 页），其后 P12 为 peak，符合规则；P16 valley → P17 peak → P18 valley，无连续 3 页 valley 违规。
- **非对称版式预算**：≥ 40%（实际约 16/19 页为非对称或自定义版式）。对称版式（上下分栏）不使用；N 卡片横排不作为整页版式使用。
